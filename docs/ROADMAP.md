# Roadmap do CoursePress Lab

## Fase 1 — Fundação local

- [x] Criar o repositório público;
- [x] configurar WordPress e MariaDB com Docker Compose;
- [x] separar variáveis locais;
- [x] criar os esqueletos do tema e do plugin;
- [ ] instalar o WordPress;
- [ ] validar o ambiente nos computadores disponíveis.

**Critério de conclusão:** uma nova máquina consegue clonar o repositório, copiar o arquivo de ambiente e abrir a instalação do WordPress.

## Fase 2 — Base comercial

- [ ] configurar identidade e estrutura do site;
- [ ] instalar e configurar WooCommerce;
- [ ] criar produto de curso;
- [ ] configurar checkout em ambiente de testes;
- [ ] definir páginas legais e transacionais.

## Fase 3 — Entrega do curso

- [ ] instalar e configurar Tutor LMS;
- [ ] estruturar curso, módulos e aulas demonstrativas;
- [ ] controlar acesso do aluno;
- [ ] conectar compra aprovada à matrícula;
- [ ] testar a jornada completa.

## Fase 4 — Conversão e integrações

- [ ] construir landing page responsiva;
- [ ] configurar formulário e captação;
- [ ] integrar e-mail transacional;
- [ ] configurar GA4 e Google Tag Manager;
- [ ] aplicar SEO técnico básico.

## Fase 5 — Código próprio

- [ ] evoluir o tema `coursepress-lab`;
- [ ] evoluir o plugin `coursepress-core`;
- [ ] registrar eventos e leads necessários;
- [ ] adicionar configurações administrativas;
- [ ] aplicar padrões de segurança do WordPress.

## Fase 6 — Qualidade e entrega

- [ ] testar navegação, compra e acesso;
- [ ] validar acessibilidade e responsividade;
- [ ] medir e melhorar desempenho;
- [ ] documentar backup e restauração;
- [ ] configurar CI;
- [ ] publicar demonstração;
- [ ] produzir screenshots e vídeo do case;
- [ ] atualizar GitHub, arthurp.tech e 99Freelas.

## Fora do escopo inicial

- pagamentos reais;
- marketplace com vários instrutores;
- aplicativo móvel;
- emissão fiscal;
- streaming próprio de vídeo;
- recursos avançados de comunidade.
